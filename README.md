- **Melon.studio Aesthetic**:

  - Interactive Custom Cursor with lerp smoothing and magnetic hover feedback

  - Built-in Web Audio API micro-SFX synthesizer (zero external audio dependencies)

- **Engineered for "No Client Work Yet"**:

  - **4 Spec Production Blueprints**: In-depth breakdowns of real-world formats including Sarthak Goswami style cultural deep-dives, Titanix Media agency sprints, and viral community growth.
  - **Live Project Brief Builder**: Prospective collaborators and studio leads can select collaboration type, platforms, and turnaround time to generate a live markdown brief with 1-click clipboard copy or direct email to `anshurajkumarsah@gmail.com`.

## 🚀 How to Run Locally

Because this project is built with standard web technologies (HTML5, Tailwind CSS, Lucide Icons, and Vanilla JS with Web Audio & Canvas), you can open it in any browser immediately:

### Option 1: Direct File Open
Double-click `index.html` or open `C:\Users\Anshuraj\.gemini\antigravity\scratch\anshuraj-portfolio\index.html` in your browser (Chrome, Edge, Firefox, Safari).

### Option 2: Local HTTP Server (e.g. Node / Python / npx)
```bash
# Using Python
python -m http.server 3000

# Using Node npx serve
npx serve .
```
Then visit `http://localhost:3000`.
